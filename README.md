# STILL HERE — Public Edition 1.0

**Research steward: Bart Salazar** · Simple Minds Studios

A privacy-first, evidence-led public history of place, kinship and continuity. Companion to [THE anonymous FAMILY](https://simple-minds-studios.github.io/the-anonymous-family/).

## Deploy
Publish only `public/index.html` as the repository root `index.html` in a dedicated public repository named `still-here`. Do not deploy `private-template/` or unreviewed research files. GitHub Pages: Settings → Pages → Deploy from branch → main / root.

## Evidence status
The historical Anna Pawneshing is not yet independently linked to Bart Salazar's family ancestor. The Seaman and Cobmoosa relationships are hypotheses. The paternal family line is family-reported, not independently verified.

## Publication rules
Living relatives are not named, mapped or linked publicly. No enrollment data, addresses, exact dates, GEDCOMs, or unredacted documents. Do not upload the private working archive to a public repository.
